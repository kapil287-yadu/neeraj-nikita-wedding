> Official Digital Wedding Invitation Website for **Neeraj & Nikita** • 10–12 December 2026 | Jaipur, Rajasthan.

---

## 🌟 Overview
A royal, bilingual (English & Hindi) interactive digital wedding invitation experience built with pure modern web technologies (HTML5, CSS3, ES6 JavaScript, Web Audio API, and Node.js).

### ✨ Features
- **Royal Traditional Theme**: Deep Royal Plum, Burgundy, and Antique Gold aesthetic with authentic Indian wedding motifs.
- **Bilingual Structure**: English primary with Hindi subtitles across all sections.
- **Vakratunda Mahakaya Background Audio**: Devotional sacred chant playing looped upon opening the invitation, with an audio toggle and Web Audio API fallback.
- **Full 3-Day Event Schedule**: Chronological view of all 10 wedding rituals with Google Calendar and Apple/Outlook `.ics` export.
- **Venue & Google Maps Integration**: Directions to *Tulsi Marriage Garden, Near Bhairo Circle, Pratap Nagar, Jaipur*.
- **Contact Details**: Direct one-tap phone links (`tel:`) for guest assistance.
- **WhatsApp & Social Share Preview**: Open Graph tags and 1200x630 banner for rich link previews.
- **Zero-Dependency & Fast**: Static assets ready for zero-config Vercel, Netlify, or GitHub Pages deployment.

## 🚀 Local Development

To run the local server:
```bash
node server.js
```
Open your browser and visit: `http://127.0.0.1:3000/`
